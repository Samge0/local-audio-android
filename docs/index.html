FAQ

常见问题.

需要什么权限？+

默认音频目录是应用专属存储, 无需任何存储权限. 选用公共目录时, Android 11+ 需授予 "所有文件访问". 悬浮窗字幕为可选权限, 可在系统设置授予. 联网权限仅用于 zip 链接下载.

字幕怎么匹配？+

与音频文件同名即可. 支持 .srt, .vtt, .ass, .ssa, 并支持语言后缀模糊匹配, 例如 "第01讲.zh.srt" 可对应 "第01讲.mp3".

换了目录, 旧的音频会丢吗？+

不会. App 会自动迁移旧音频: 同名同大小跳过, 同名不同大小加 " (n)" 后缀共存.

有桌面版吗？+

有. 桌面 Web 版为 local-audio 项目, 功能对等. 本项目无 iOS 版.

zip 链接导入失败？+

请确认链接是直链, 例如 GitHub Release 资产直链. 导入目标为当前音频目录, 可在导入框指定子目录.
